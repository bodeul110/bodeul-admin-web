# 개발 관리자 심사 목록 복구

## 판단

- 작업 목적: 개발 관리자 로그인 후 심사 목록에서 발생하는 서버 인증 오류를 해결하고, 조회 실패를 대상 0명으로 표시하지 않는다.
- 확인한 원인: 2026-10-29 Vercel Preview의 `/admin/manager-reviews`에서 Google 기본 자격 증명을 찾지 못했다. 로그인용 ID token 서명 검증과 PostgreSQL 예약 조회는 성공했으나, Firestore 조회에 사용할 서버 인증은 설정되지 않았다.
- 선택한 방식: 인증 누락은 Firestore ADC 탐색 전에 구분된 오류로 반환한다. 화면은 조회 중·실패·성공을 구분하고 실패 시 재시도를 제공한다. 심사 목록 오류는 대시보드와 매니저 승인 화면에만 표시한다.
- 대안: 빈 목록 반환이나 오류 숨김은 실제 미조회 상태를 정상으로 오인하게 하므로 사용하지 않는다. 운영 자격 증명 복사와 광범위한 서비스 계정 키 재사용도 제외한다.
- 선택 이유: 현재 MVP에서 예약 조회와 심사 목록은 별도 데이터 경로이므로, 심사 장애가 정상적인 예약 시연을 가리지 않게 하되 실제 장애는 해당 화면에 남겨야 한다.
- 리스크: 이 방어 코드만으로 Firestore 연결이 복구되지는 않는다. 개발 서버 인증과 최소 읽기 권한을 별도로 설정하고 실제 Preview에서 검증해야 한다. 목록 조회 성공은 서류 열람·승인·반려·운영 업무 활성화를 뜻하지 않는다.

## 검증과 적용

코드 검증, 개발 인증 설정, Preview 배포와 실제 조회 확인을 구분해 기록한다. 운영 환경과 기존 계정의 비밀번호·권한은 변경하지 않는다.

- 구현: 서버 인증 누락 오류와 실패 감사, 민감한 내부 오류 비노출, 로컬 ADC 경로 보존, 목록 상태·재시도 표시.
- 인증 연결: 개발 Preview 전용 OIDC/WIF 읽기 연결의 권한 및 SDK 추가 승인 대기. 아직 실행하지 않음.
- 실기기: 사용자 요청에 따라 이번 검증에서 제외.
- 시연 범위: 기존 가상 예약과 완료 리포트 조회. 신규 예약·매칭·심사·결제 변경과 DB seed는 별도 실행·검증 전까지 성공으로 기록하지 않는다.

근거: [Firebase Admin 서버 설정](https://firebase.google.com/docs/admin/setup), [Vercel의 Google Cloud OIDC 연결](https://vercel.com/docs/oidc/gcp).
